# Teesha Ramchandani · Portfolio

Personal portfolio of **Teesha Ramchandani**, final-year B.Tech in Data Science & Artificial Intelligence at IIT Bhilai and former Software Engineering Intern at Visa.

## Features

- **Interactive knowledge graph** linking internships, projects and skills. Drag, hover or tap the nodes.
- **FinManAI architecture explorer:** tap any engine or stage to see what it does.
- **Working terminal:** try `help`, `projects`, `finmanai` or `sudo hire teesha`.
- **Command menu:** press `Ctrl K` (or `/`) anywhere to jump around.
- **Light and dark themes** (press `T`) with an animated ambient background.
- **Photo galleries** from the Visa internship, sports and CCPS.

## Tech

A single static `index.html` with plain HTML, CSS and JavaScript, using no framework and no build step. Fonts come from Google Fonts; photos live in `assets/`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Hosted with GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
